## Topics Covered

- **TypeScript Compilation:** The TypeScript Language Server (LSP)
  helps detect and report errors, while the TypeScript CLI (`tsc`)
  compiles `.ts` files into JavaScript.
- **`tsconfig.json`:** Introduced as the TypeScript compiler
  configuration file.
- **Type vs. Interface:** Practiced using `type` aliases and
  `interface` to describe object structures and other types.
